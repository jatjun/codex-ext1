# 动画规范

CSS preserve-3d 绘制六个原创面，角度由数学方向映射确定。正方体160×160×160；长方体160×70×100。所有面始终存在，使用背面隐藏与透视表达可见性，不用DOM计数计算数学答案。

方向按钮与Pointer Events拖动共用状态，700ms连续旋转，提供0.5/1/1.5速度；转动期间锁定方向输入避免连点竞争。播放控制分步时间线，关键问题自动停下。暂停通过Web Animations API暂停现有CSS transition，继续恢复；重播回到前视图与第一步，不删除历史尝试。

步骤跳转不能跨越未通过的关键题；支持减少动态效果偏好。V1未实现通用物体分组合并、十进制拆分或任意纸盒折叠引擎，这些不属于截图已完成场景。

## 混合运算 SVG
`mixed.ts`提供固定数量、来源与目标坐标；`MixedStage`只负责在坐标之间用requestAnimationFrame插值，不从DOM计算答案。酸奶18蓝＋4橙合并为22；桃子25绿＋15橙先合为40，再分5盒，每盒8个。稳定ID不随步骤变化。暂停保留插值进度，调速影响后续时间增量，重播重新建立初始布局。每个动画1600ms/速度，自动步骤间隔2800ms/速度，关键预测停下。SVG viewBox适应手机；不使用教材图片或第三方资源。
