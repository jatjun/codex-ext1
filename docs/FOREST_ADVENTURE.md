# 萤光森林：小狐狸的晶桥奇遇

入口：`https://jatjun.github.io/codex-ext1/#forest`，课程首页也有“新冒险”入口。

## 本轮关卡
面向6～9岁，目标时长约3～5分钟（尚未经儿童实际试学计时）。自由探索，不设倒计时、失败惩罚、账号或付费。游戏进度只保留当前会话，刷新后重新开始。

1. 起始林地散布12颗绿色水晶，每次背包最多4颗。靠近自动收集，树桩上的两颗需要跳跃拿取。
2. 三个机关树桩各有4个可视插槽。孩子靠近按E/点放入，每次只转移1颗。每装满一组升起4块桥板，三组完成才可过河。界面自然呈现4×3＝12，不弹出试卷。
3. 对岸3颗紫色与2颗金色水晶，要再次搬运并逐颗放进花门。颜色及总数都必须满足条件，呈现3＋2＝5。走进花门触发跳舞、粒子庆祝和方法回顾。

键盘：WASD或方向键移动、空格跳跃、E放入。触屏：左侧摇杆移动、右侧跳跃与放入按钮。地图显示狐狸、剩余水晶、树桩及花门。声音默认关闭，点击音符启用本地合成音效。页面切到后台自动暂停。

## 实现与隐私
使用Three.js（MIT）WebGL，原创几何狐狸、树木、草花、机关和水晶；无下载模型、教材图或远程纹理。程序化水波、水流、萤火虫、局部光晕及通关粒子。角色关节独立行走，带呼吸、摇尾与跳跃动作。

数学状态在`src/adventure/model.ts`，渲染与碰撞在`world.ts`，界面在`Adventure.tsx`。场景合并静态网格降低绘制次数，缓存静态阴影；识别软件渲染时降低分辨率并关闭阴影。3D资源仅进入游戏时按需加载。无需第三方API，音效由Web Audio生成，不上传数据。

无WebGL时显示明确说明和返回入口。真实iPhone Safari与低端手机性能尚未实测，不能将自动化390px测试等同真机兼容性。

## 三科入口首版
`#academy`提供语文、数学、英语三个分区。语文为识字/词语配对，英语为动物/颜色词配对，数学为数量配对及现有3D森林。语言活动是基础二维配对，尚未实现3D剧情、完整小学课程、教材版本对齐、跨关掌握判定和持久进度。后续应逐关增加物体操作与知识迁移，不能把入口或少量配对视为完整课程。

森林增加满包卸货提示、剩余水晶数及左右方向提示，避免孩子把无法继续拾取误认为水晶消失。

三科活动扩展为各8关（共24个入口，含原有3D晶桥）。新增语文自然汉字、水果、量词、反义词、动作、句子；数学合并、分组、平均分、购物、时间与括号；英语水果、数字、天气、身体、动作与问候。配对活动通关后直接进入下一关；这些仍为基础二维互动，不等同24个3D关卡或完整小学课程。

- 画质偏好仅保存在本机localStorage的forest-quality；无联网上传。关卡进度仍是会话内状态。

## 2026-10-26：NPC工坊、读词符咒与本机升级
新增第6/7关，每科再增加两条路线，共21条、5类场景。霓光港口有蓝紫地面、彩色晶簇、船只与发光环；云端学园有星象穹顶与彩色步道。二者保留通用控制与守卫机制，不应宣称为21套完全独立游戏。

导师露米位于(3,14)，4个游戏单位内可按E或点击交谈。先显示故事对话，再进入独立工坊界面，完成小游戏才蓄力：数学为星果数量搭建/算式翻牌；语文为指定语序排句/反义词翻牌；英语为目标词拼写或可选读词。工坊期间世界暂停。错误答案、未蓄力、选错守卫编号都不会命中；命中后能量消耗，不可重复刷同一守卫。

升级存档fox-hero-v1仅保存版本和已奖励任务ID。每项首次小游戏/守卫20XP，首次通关60XP，每100XP一级，重复任务幂等。森林原有通关也可获首次60XP。Lv.2紫色围巾、符文光效；Lv.4金色围巾。等级与称号属于游戏进度，不是掌握判定。浏览器存储损坏时安全恢复，保存失败时明确提示；无账号、云同步或姓名资料。

## 2026-10-27 本地进阶扩展

新增索引7/8/9的集市、矿洞、城堡，位置统一由 `expeditionLayout` 提供给小地图和3D场景，避免指引与守卫不同步。`regions.ts` 绘制原创摊位、轨道矿车、城墙等装饰；新区域不增加阻断主路径的装饰碰撞。

`story-model.ts` 保存题意和两步运算，不使用eval。`StoryGame` 逐步验证，再把两步答案交给 `trialCorrect` 复核；只给最终答案不能充能。加减变化使用稳定SVG物体移动/显隐，乘法逐组摆出，除法重新分组。结果保持整数，单位按步骤切换；错误与使用提示信息单独记录，不用经验值判断是否掌握。

装备从已保存的 `spirit2` 奖励事件派生：任意学科索引7对应法杖、8对应提灯、9对应护盾。同一物品不重复添加，未解锁ID不能被装备选择接口接受。穿戴附着于探险狐狸模型，并改变发射光弹颜色；装备效果仅外观，不自动解题。奖励宝箱出现在第三个守卫旁，恢复该守卫时自动领取，不要求孩子另找隐藏拾取点。

本轮不推送，不触发Pages；场景视觉、触屏和完整通关仍须在具备浏览器执行权限的环境中完成回归。
