# 教学设计

两个完整流程：故事与预测 → 操作方向按钮或拖动 → 必答关键预测 → 验证讲解 → 独立练习 → 表面不同的迁移题。

观察方向：一个长方体始终保持一个，观察位置改变；长宽高对应不同面。圆柱上视图与球各方向轮廓验证迁移，强调“常常不同”并非“总是不同”。

数字盒：固定六面与相对关系 → 前后追踪 → 预测后面的数字 → 7−1=6 → 左右相对练习 → 相对和变成9的新题。显示隐藏面以验证推理，不把旋转当作数量改变。

答错首轮给局部提示，特定“所有的面”错误提示遮挡；第二次错误给完整解释并切换观察方向。允许重试。解释后的正确单独记录。答对后邀请口头说明，V1不自动评价儿童开放式口述。
