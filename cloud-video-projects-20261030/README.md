## 获取

打开视频文件页，使用 Download raw file 下载。完整项目可以下载各目录内 ZIP 包，也可以使用仓库 Code → Download ZIP。

manifest.json 与 SHA256SUMS.txt 记录本次归档的原文件大小和 SHA-256，可用于下载后核对。源码里的云端绝对路径需按使用环境调整；各项目 README 中包含运行说明。

二维/三维汽车美容视频均为模拟动画，不是实拍洗车录像。没有第三方图库素材或音乐。字体使用环境预装的 Noto CJK，未分发字体文件；三维项目保留字体许可说明。
