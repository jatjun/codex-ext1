## 小小数学观察家 V1

基于本次上传“观察物体”第1～5页，提供两个原创动态观察场景：长方体视图、数字正方体相对面。包含关键预测、分支提示、6道配套题、中文可选朗读、本地记录及JSON导出。未接入真实AI；教材截图不随应用分发。

### Windows本地运行

安装 Node.js 22.12+（建议24 LTS）与Git，然后在PowerShell执行：

```powershell
git clone https://github.com/jatjun/codex-ext1.git
cd codex-ext1
git checkout feat/interactive-math-v1
npm ci
npm run dev
```

打开终端显示的本机地址（地址包含 /codex-ext1/）。生产构建：`npm run build`。逻辑测试：`npm test`。浏览器测试：`npx playwright install chromium`，然后 `npm run test:browser`。

### iPhone访问

电脑和iPhone连同一Wi-Fi，保持`npm run dev`运行；查看电脑局域网IPv4地址，在Safari访问 `http://电脑IP:5173/codex-ext1/`。按Windows提示允许Node在专用网络通信；不要把开发服务器暴露到公网。开发环境远程地址不等于可从手机访问的地址。中文声音取决于设备安装情况，无中文声音会显示文字回退说明。

### 3D森林冒险
[直接试玩《小狐狸的晶桥奇遇》](https://jatjun.github.io/codex-ext1/#forest)：收集、跳跃、搬运水晶，三组各4颗修桥，再用3颗紫水晶＋2颗金水晶唤醒花门。支持WASD/方向键、空格、E及手机摇杆；无需登录和付费。详见[玩法与技术说明](docs/FOREST_ADVENTURE.md)。

3D冒险现有语数英各7关，共21条任务路线、5类场景；不是21张独立地图。第1～3关为森林搬运与分类，第4～5关为沙漠、冰雪符文战斗，第6～7关为霓光港口、云端学园。开场选关，通关后可继续下一关。

第6～7关先靠近猫头鹰导师按E交谈，进入数量工坊、句子/拼词卡片或翻牌配对小游戏。解题成功才给对应攻击蓄力，再选符文按F发射。英语另有可选的浏览器读词识别：**须每次主动同意后启动，语音可能由浏览器服务商在线处理**；只有识别文本匹配目标词才蓄力，不是专业发音评分。无语音支持时使用离线拼词，不会假装语音成功。

回声门原有的MediaRecorder录音回听仍完全在本页内存中，不上传，关闭即清理；它与上述可选在线语音识别是两项不同功能。本网站不保存识别文本或录音。

新增本机经验与等级：首次完成小游戏/解救守卫各20XP，首次通关60XP，每100XP升一级；重复完成同一任务不再奖励。Lv.2解锁紫色围巾与符文光效，Lv.4解锁金色围巾。只记录任务编号，保存在本浏览器localStorage；同一浏览器共享档案、不跨设备同步，清除网站数据会重置。等级不代表学业掌握程度。

右上角可选低／高／极致画质（默认高，记住选择）。极致增加后期辉光、更高像素密度和阴影；主要自动化使用低画质，单独验证极致渲染。点“字”开关森林提示；装满时可把水晶放回原处。详见 `docs/FOREST_ADVENTURE.md`。

### 自动换题与家长题库
树王战默认“自动变化”，数字随机、题型打乱，尽量避开最近8题；题型模板仍为六类，不是无限语义题库。点击战场“家长题库”可新增/编辑/启停/删除题目（最多100题），数学算式自动算答案，文字及应用选择题需家长确认题意和唯一答案。程序能校验结构与规范算式，不能自动验证任意自然语言题目。
题库在本机 `fox-custom-questions-v1` 保存，刷新保留、不跨设备同步；可下载JSON或粘贴JSON合并导入，重复ID保留已有题，不自动覆盖。战斗选择自动、混合或仅自定义来源，按当前难度筛选；该难度没有自定义题时回退自动，一道自定义题无法避免重复。题库编辑期间暂停战场，已出现的攻击题保持不变，更新从下一题生效。此入口是家长使用界面，不是账户级访问控制，请勿填儿童隐私。

### NPC补给战斗模式
从地图点击“NPC补给战斗”，或打开 `#forest?boss=1&mode=supply`。即时答题练习模式保持独立，家长设置也可切换模式。

1. 新战斗生命100、弹药0。按蓝点走到蓝帽导师附近（4步），点击“找导师补给”或按E答题；答对每题+3弹药、+1技能点，可反复答题。
2. 展开“武器与技能”：法杖消耗1弹/造成1伤害，双发消耗2弹/造成2伤害；2点治疗+30生命或增加30护盾（最多60）。治疗不超过100，满血/满盾不会消耗点数。
3. 小怪生命3，近6步可攻击，树王近10步可攻击。补给模式攻击直接消耗弹药，不再每次弹题；不足时回导师。怪物攻击先扣盾再扣生命，每次12伤害，有2秒受击保护。生命归零可免费重试。
4. 三只小怪分别掉爱心（+25生命）、弹药（+4）和叶晶装备（解锁叶晶法杖，并+2技能点）；走近自动拾取。装备解锁沿用本地英雄存档，可在本战场选择或普通探险背包穿戴，叶晶外观不额外提高伤害。

战斗中的生命、弹药、技能点和护盾只保留本局，刷新/退出重新开始；永久装备、首次经验和已有材料仍保存在当前浏览器。小怪和树王有实体五官/肢体、血条及投射物尾迹；即时练习模式显示固定100生命并明确不扣血。原先“不扣血”不适用于新补给模式。主画面/关卡地图导航在刷新前设置地址，避免回到原战斗。

### 三波守城与永久强化
新增入口 `#forest?boss=1&mode=supply&waves=1`，地图与战斗设置均可进入。三种敌人：追踪怪、快速摆动的疾行怪、慢速高血量重甲怪；每波生命上升。清理一波后可安全补给，手动点击“准备好了，下一波”；清完第三波才解锁树王，提前攻击树王不浪费弹药。
装备工坊可消耗真实材料强化武器/技能，均最高3级：补给模式每级武器伤害+1，弹药成本不变；每级技能治疗/护盾量+5，消耗仍2点。永久数据存于 `fox-forge-v1`，材料支出与等级用同一次本地写入保存；累计掉落总数不被改写，可用余额为累计获得减已消耗。胜利面板显示累计获得，工坊显示余额。写入失败会报告失败，不能算强化成功。
拾取小怪的装备掉落额外获得一件轮换材料；重玩可继续获得材料。没有付费或账户系统，清理浏览器存储会失去强化和材料。波次、弹药、生命仍是本局状态。

补给战斗与三波守城中的树王现有24点生命（原为3点）；强化武器也需多次命中。小怪从左右外围和后方进入战场，每波重新从外围出发。入门符文练习仍保留三层护盾。

进阶入口“多怪挑战”在地图和战斗设置中可选：三波分别4、5、6只小怪（共15只），清理每波后可自由补给，再手动开始下一波。界面显示本波剩余数量。小怪全部清理后才可攻击24生命树王。普通三波每波3只，适合先练习；多怪挑战建议先在工坊强化武器、准备治疗与护盾。

导师周围青色圆圈是补给安全区：不会被怪物撞出范围，也不会受到范围攻击伤害；安全区内不能攻击、不消耗弹药。答题仍暂停战斗，补给完成后走出圆圈再施法。

补给战斗新增两种主动技能（展开“武器与技能”）：Shift/按钮“冲刺闪避”消耗1点，沿面朝方向冲出约4.8步，短暂无敌，冷却4秒；Q/按钮“冰霜减速”消耗2点，使释放时8步内的小怪降至30%移速，持续4秒，冷却8秒。工坊技能强化每级延长冰霜0.5秒。红圈仍需躲避；附近没有小怪或身处安全区时冰霜不消耗点数。答题、暂停、设置和教学提示期间计时暂停，技能不在这些状态下触发。技能和弹药状态只保留本次战斗。

进阶入口“投弹突围”保留4/5/6只三波挑战，每波将一只重甲怪替换为橙帽投弹怪。它会在约4～7步距离周旋，抛出弧线魔法弹；橙圈提前1.8秒标出固定落点，击中扣12生命（先消耗护盾）。走出半径2.2步、冲刺无敌或导师安全区可避免该次伤害。冰霜同时减慢它的移动和下一次投弹准备；已在空中的弹不会被冰霜取消。换波会清除上一波未落地的投弹。

波次间可选奖励：普通三波、多怪挑战和投弹突围的前两波清理完成后，进入安全休整，未落地投弹和红圈清除，树王暂不产生范围攻击。可选择一次弹药+6、生命+25或技能点+2（遵守各自上限；已满的奖励禁用，不消耗选择机会），也可跳过、找导师继续补给，再手动开始下一波。第三波后直接挑战树王并保留原胜利掉落。奖励选择仅保留本次战斗，退出重开后需重新清怪。

战斗环境：在“家长设置 → 战场环境”选择萤光森林、星晶矿洞或极光雪原。矿洞有晶簇、轨道、矿车与流光环，雪原有雪山、冰面与飘雪；光照、地面及树王配色随场景改变。暂停、答题和教学提示时环境动效冻结。三种环境共用圆形场地布局及战斗规则，属于不同视觉环境，不是三套独立地图。切换会重新开始当前战斗；发布模式参数与本机装备、材料、题库仍保留。
